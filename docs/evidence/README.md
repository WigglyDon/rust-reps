# Evidence discipline

Report what was observed, under which source and execution conditions, and what
remains unknown. Distinguish Don's decisions from implementation facts, measured
runtime, independent external evidence, agent claims and inference.

Tests establish exercised software contracts. Transcript tests establish actual
stdout/stderr/exit behavior. Synthetic frame tests establish bounded rendering
and privacy behavior. A real-terminal playtest is needed for feel; Don's use and
feedback are needed for learning value. Model consistency does not prove
physical hardware correspondence, and copying a line does not prove mastery.

Issues carry decision-useful validation and handback. Retain relevant failure
logs and source identities in ignored local evidence; publish only safe summaries
and references. An earlier report is not an independent rerun. Existing
[runtime schemas](RUNTIME_EVIDENCE_SCHEMAS.md) are optional historical formats,
not mandatory packet ceremony or new product authority.
