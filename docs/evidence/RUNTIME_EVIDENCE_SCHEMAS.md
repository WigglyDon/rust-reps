# Runtime Evidence Schemas

Context role: Canonical Rust Reps runtime/evidence record schemas.
Scope: Structured fields for CLI, install, TUI, procgen, tools, and integration evidence.
Canonical for: Required evidence fields and explicit unavailable representation.
Not canonical for: Product acceptance, deployment authority, or fabricated observations.
Inherits: [`README.md`](README.md) and [`../../AGENTS.md`](../../AGENTS.md).
Current-state owner: [`../context/CURRENT_STATE.md`](../context/CURRENT_STATE.md).
Related evidence: External checksummed manifests generated by fleet tooling.
Update triggers: Required field, proof class, product surface, or integration schema changes.

Each record uses stable `key<TAB>value` lines, UTF-8, LF endings, and explicit
`UNAVAILABLE:<reason>` values. Multiline/raw bytes live in separate checksummed
artifacts referenced by path and SHA-256.

## CLI Transcript Record

Required: `record_type`, `source_sha`, `executable_path`, `command`, `stdin_sha256`,
`stdout_sha256`, `stderr_sha256`, `exit_status`, `environment`,
`unavailable_facts`, and artifact paths for exact byte captures.

## Installed-Command Record

Required: `record_type`, `source_sha`, `install_command`, `install_exit_status`,
`command_v_output`, `installed_executable_path`, `version_command`,
`version_stdout_sha256`, `smoke_commands`, `smoke_results`, and `unavailable_facts`.

## TUI Manual Playtest Record

Required: `record_type`, `source_sha`, `terminal_environment`, `terminal_size`,
`action_sequence`, `observed_result`, `don_judgment`, `limitations`, and
`capture_artifacts`. An unavailable real TTY is explicit; redirected output is
never labeled fullscreen or mouse proof.

## Deterministic Procgen Record

Required: `record_type`, `source_sha`, `template_id`, `template_version`,
`domain_versions`, `seed`, `generated_provenance`, `prompt_sha256`,
`stimulus_sha256` (or explicit unavailable), `expected_sha256`,
`duplicate_output_result`, and `expansion_result`.

## Tool-Runner Record

Required: `record_type`, `source_sha`, `request_label`, `tool_kind`,
`executable`, `arguments`, `stdin_sha256`, `timeout_ms`, `output_limit_bytes`,
`stdout_sha256`, `stderr_sha256`, `status`, and `failure_class`.

## Release/Integration Record

Required: `record_type`, `integration_sha`, `parent_sha`, `context_sha`,
`candidate_commits`, `targeted_gates`, `full_verification`,
`runtime_evidence_state`, `artifact_checksums`, `authority_changes`,
`rollback_state`, `observability_state`, `performance_resource_state`,
`deploy_state`, `push_state`, and `recovery_restart_evidence`.

The repository contains the schema and generator. Final records live outside
the repository so their final integration SHA does not create a self-reference.
