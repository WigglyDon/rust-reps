# Continuation and handback

Resume from the authorized GitHub issue, current repository owners, source and
live Git/resource observations. Revalidate identity, scope, ownership and relevant
remote freshness; preserve unknown changes and donor work. Old packets, lane
labels and stale chat state do not restart work.

A handback records the completed outcome, source/artifact identities, actual
checks and failures, limits, unresolved decisions and released resources.
Detailed logs belong in their proper local owner. Another agent treats a report
as a claim until independently checked. Don does not need to carry routine
reports or repair Git mechanics.

Stopped sessions do not imply background work. The historical respawn-bundle
command is optional packaging, not a worker launcher or task grant.
[Development](../DEVELOPMENT.md) owns the current workflow.
