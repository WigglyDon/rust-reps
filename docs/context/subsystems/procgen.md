# Static expansion and guidance

Procgen defines pure locale-independent expansion and reviewed static materialization. It does not generate live product tasks. Planner selects supplied admitted candidates; guidance resolves explicitly selected authored locale/keys without answer ownership or fallback. The product uses resolved English guidance; other proof locales are not learner features.

[Architecture](../CONTEXT_MATRIX.md) owns dependency boundaries; [current state](../CURRENT_STATE.md)
owns implementation status; [curriculum design](../../CURRICULUM.md) owns the
new teaching direction.

Validation: Deterministic expansion/planning, guidance resolution failure and isolation tests.
Use [development](../../DEVELOPMENT.md) and [evidence](../../evidence/README.md)
for task authority, required checks and claim limits.
