## Mission And Authority

Lab supplies endless deterministic exercise-shaped packets that pressure
wrapping, viewports, multiline answers, syntax display, and layout. It is
entered only through explicit lab mode.

Allowed authority is synthetic test data and stress-family selection. Forbidden
authority is normal rep IDs, catalog registration/listing, learner evidence,
curriculum progression, or validator integration. Engine may select lab as an
explicit source; catalog must never import it.

## Proof And Limits

Accepted proof covers deterministic families, uniqueness, packet compatibility,
catalog isolation, multiline Exact behavior, and client/TUI projections.
Automated stress tests do not prove final feel or learning quality. Runtime
integration exists only behind `rust-reps lab`; piped lab fails as a CLI error.

Rollback removes a stress candidate or restores a prior family without touching
normal curriculum. Observability is visible lab behavior and deterministic test
packets; there is no telemetry. The endless index is synthetic and does not
represent stored content.

## Gate And Unknowns

Lab cleanup and new families are paused. No mutation or curriculum authority is
planned. Update for launch, family, isolation, validation, or product-listing
changes.
