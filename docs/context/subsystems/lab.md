# Synthetic client lab

The lab supplies deterministic synthetic stress packets independently of the ordinary curriculum. It exercises editor/rendering/scrolling/formatting mechanics; lab output does not enter normal listing or establish learner quality. Launch requires an interactive terminal.

[Architecture](../CONTEXT_MATRIX.md) owns dependency boundaries; [current state](../CURRENT_STATE.md)
owns implementation status; [curriculum design](../../CURRICULUM.md) owns the
new teaching direction.

Validation: Lab packet tests, CLI launch/error proof and actual terminal observations when feel is claimed.
Use [development](../../DEVELOPMENT.md) and [evidence](../../evidence/README.md)
for task authority, required checks and claim limits.
